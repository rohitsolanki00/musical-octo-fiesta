PARO ♥ LADDUUU — HOSTING GUIDE

Files:
- index.html          Main website (3 pages: Home, Love Letter, Mini Game)
- assets/style.css    Styling, responsive layout, animations and CSS anime couple
- assets/script.js    Page navigation, secret note, heart-catching game and optional synthesized chime

How to preview:
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Internet is only needed for the optional Google Fonts; the website itself works without them.

How to host:
- Netlify: drag the extracted folder (or upload its contents) to Netlify Drop.
- GitHub Pages: upload all files to a repository and enable Pages from the repository settings.
- Any standard static hosting: upload index.html and the complete assets folder, keeping their folder structure.

No image files are used. The anime-style boy and girl are drawn with CSS shapes, so you can host the project without an image-assets folder.
